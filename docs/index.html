Core Architectural Pillars

A coherent, production-ready foundation designed for network protocols, file formats, and high-throughput serialization.

🔌

Unified Binary I/O Engine

A single polymorphic interface hierarchy (Readable / OwlReader and OwlWriter) that abstracts underlying storage targets.

  • Write binary parsing and serialization logic once against common interfaces.
  • Switch seamlessly between heap arrays, network streams, and off-heap memory without rewriting protocol code.
  • Full position tracking, relative seeks, peeking, and skipping.
📐

Comprehensive Protocol Encodings

First-class support for binary standards, custom endianness, and variable-length compression.

  • Endianness Control: Seamless Big-Endian and Little-Endian switching on the fly.
  • Primitives: Signed/unsigned 8, 16, 24, 32, and 64-bit integers, floats, and doubles.
  • Safe Unsigned Checks: Explicit overflow verification (readSU*, writeSU*).
  • VarInt & ZigZag: Protocol Buffers LEB128 compatible variable integers with 1-byte encoding for small negative values.
  • String Protocols: Fixed-width, null-terminated C strings, 1/2/4-byte Pascal strings, and line-based formats.
✂️

Zero-Copy Slicing, Framing & Integrity

Advanced stream decomposition and packet framing with built-in checksum validation.

  • Zero-Copy Slicing: reader.slice(length) creates independent sub-readers without allocating or copying buffer contents.
  • Deterministic Framing: reader.frame(length) isolates packet windows; closing a frame skips remaining bytes to ensure parent stream alignment.
  • Inline Checksums: CRCByteArrayOwlReader computes rolling CRC32 values during reads without separate passes.
🔄

In-Memory Buffer (Reader & Writer APIs)

A high-performance, dynamic buffer combining reader and writer APIs in a single structure.

  • Simultaneously implements ReadableBuffer and WritableBuffer with fluent method chaining.
  • Ergonomic unchecked exception handling (throws UncheckedIOException).
  • Delimiter-based scanning via readUntil(byte) and readThrough(byte).
  • Direct bridging with Java NIO Channels via readFrom() and writeTo().

Core Usage Patterns

Explore how OwlReader simplifies binary serialization and packet parsing.

Pattern 1: Polymorphic Binary Protocol Serialization Endianness & Mixed Types 
// Polymorphic writer works identically across arrays, streams, NIO, and native memory
public void writePacket(OwlWriter writer) throws IOException {
    writer.setEndian(Endian.BIG);
    writer.writeInt24(0x4F574C);               // 3-byte magic header ("OWL")
    writer.writePascalShort("Client-Session");  // 2-byte length-prefixed string
    writer.writeVarInt(1048576);                // Protobuf-compatible VarInt
    writer.writeSignedVarInt(-42);              // Compact ZigZag-encoded integer
    writer.writeDouble(98.6);                   // 64-bit IEEE float
}
Pattern 2: Zero-Copy Slicing & Framed Stream Demuxing Zero Allocation & Boundary Safety 
// Read packet length, then frame the stream to enforce strict boundary safety
int packetLength = reader.readInt();

try (OwlReader packet = reader.frame(packetLength)) {
    // Zero-copy slice header without copying bytes
    OwlReader headerSlice = packet.slice(8);
    short messageType = headerSlice.readShort();
    int sequenceNum   = headerSlice.readInt();

    // Read payload safely; closing the frame skips any unread padding
    byte[] payload = packet.read(packet.available());
}
// Parent reader is automatically aligned to the start of the next packet!
Pattern 3: In-Memory Buffer Supporting Reader & Writer APIs Dynamic & Unchecked Exceptions 
// Dual reader/writer buffer with fluent chaining and delimiter searching
Buffer buf = new Buffer();

// Write using fluent builder API (no checked IOException)
buf.writeBytes24(0x123456)
   .writeVarInt(500)
   .write("Header: Value\r\nBody Content\r\n");

// Read back from the same buffer structure
int magic = buf.readInt24();
int count = buf.readVarInt();

// Delimiter scanning
String line = buf.readUntil((byte) '\n'); // "Header: Value\r"
