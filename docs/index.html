Modern Binary I/O & Buffering

A high-performance Java 21 library delivering zero-copy slicing, VarInt & ZigZag codecs, 24-bit medium integers, Panama MemorySegment, and unified stream framing.

Browse Javadoc API View on GitHub

Core Features

⚡

Zero-Copy Slicing

Split, slice, and delegate binary streams with reader.slice(length) across byte arrays, memory segments, and direct buffers without allocations or byte copying.

📦

VarInt & ZigZag Codecs

Standard Protocol Buffers LEB128 compatible variable-length integers and 64-bit longs. ZigZag encoding maps small negative numbers to a single byte.

🎯

24-Bit Medium Integers

Native 3-byte protocol header operations with signed readInt24(), unsigned readUInt24(), and writeInt24() across Big and Little Endian.

☕

Java 21 Panama FFM

First-class integration with Foreign Function & Memory via MemorySegmentOwlReader and MemorySegmentOwlWriter for off-heap performance.

🛡️

Unified Framing & CRC

Enforce strict frame boundaries with reader.frame(length) and compute rolling CRC32 checksums on the fly with CRCByteArrayOwlReader.

🔄

Fluent In-Memory Buffers

Rich, fluent Buffer abstraction providing unchecked exception semantics, auto-expansion, delimiter scanning, and NIO Channel read/write.

Quick Start Examples

Reading & Writing Medium Integers and VarInts Java 21 
// In-memory buffer with fluent chaining
Buffer buffer = new Buffer();
buffer.writeInt24(0x123456)
      .writeVarInt(300)
      .writeSignedVarInt(-42)
      .writeString("OwlReader");

// Reading primitives back
int header = buffer.readInt24();          // 0x123456
int count  = buffer.readVarInt();         // 300
int delta  = buffer.readSignedVarInt();   // -42 (compressed via ZigZag)
String tag = buffer.readString(9);        // "OwlReader"
Panama Native MemorySegment Zero-Copy I/O Java 21 FFM 
try (Arena arena = Arena.ofConfined()) {
    MemorySegment segment = arena.allocate(1024);
    MemorySegmentOwlWriter writer = new MemorySegmentOwlWriter(segment, Endian.BIG);
    writer.writeInt24(0xAABBCC);
    writer.writeLong(123456789012345L);

    MemorySegmentOwlReader reader = new MemorySegmentOwlReader(segment, Endian.BIG);
    assertEquals(0xAABBCC, reader.readInt24());
    assertEquals(123456789012345L, reader.readLong());
}
